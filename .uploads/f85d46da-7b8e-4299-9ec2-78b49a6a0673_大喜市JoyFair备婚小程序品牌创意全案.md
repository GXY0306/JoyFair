# 大喜市 JoyFair 备婚小程序品牌创意全案

## 一、项目概述
Z世代已成为备婚主力人群，传统婚庆平台普遍存在信息冗杂、套路感重、过度营销、审美陈旧等问题，年轻人备婚普遍面临「怕麻烦、怕踩坑、怕千篇一律」的三大痛点。

**大喜市 JoyFair** 以「市集化」为核心差异化，将繁琐的备婚流程重构为一场轻松好逛的婚礼主题市集，主打「好玩、好逛、好省、有搭子」四大价值，打造面向22-30岁年轻群体的潮玩向备婚服务平台，用市井烟火气消解备婚焦虑，用创意玩法重塑备婚体验。

## 二、品牌核心体系
### 2.1 品牌定位
中国首个Z世代**市集型潮玩备婚小程序**——把备婚变成逛市集的乐趣，拒绝备婚焦虑，拒绝婚庆套路，做新人身边接地气、懂年轻人的备婚伙伴。

### 2.2 品牌核心主张
**反备婚焦虑 · 反婚庆套路 · 反千篇一律**
- 拒绝“完美婚礼”绑架，主张轻松随性的备婚节奏
- 摒弃行业隐形消费与话术套路，用市集的透明感建立信任
- 不推崇标准化模板，鼓励新人打造专属个性婚礼

### 2.3 品牌核心价值
1. **轻松感**：消解备婚的沉重感与任务感，用逛玩的心态完成筹备
2. **烟火气**：跳脱高端奢华的婚庆话术，用市井感贴近真实备婚生活
3. **个性化**：精选小众创意婚品与玩法，拒绝千篇一律的通货婚礼
4. **社交感**：搭建同频新人交流场，备婚路上有人搭伴不孤单

### 2.4 Slogan体系
#### 主Slogan
**来大喜市，办大喜事**
> 对仗工整、朗朗上口，自带市井烟火气，直白关联品牌名与核心场景，像邀约朋友逛市集一样轻松，精准传递「开心备婚」的内核。

#### 场景副Slogan
- 品牌情绪向：备婚不赶进度，只逛喜欢的路
- 功能价值向：逛遍婚品灵感，玩出婚礼新鲜感
- 社交互动向：找搭子，凑乐子，一起备婚事
- 活动促销向：每周赶喜集，省钱又省心

## 三、品牌视觉识别系统
### 3.1 Logo设计规范
- **中文名「大喜市」**：采用圆润饱满的卡通书法字体，弱化传统婚庆的正式感；将“喜”字中部两个“口”变形为笑脸符号，底部笔画模拟市集摊位屋檐轮廓，强化场景联想。
- **英文名「JoyFair」**：搭配圆润无衬线字体，字母“o”设计为迷你柿子图形，与品牌IP呼应，置于中文名下方，整体比例轻盈活泼。
- **应用原则**：最小应用尺寸不小于24px，保留四周安全距离，禁止拉伸变形、更改配色。

### 3.2 色彩体系
跳出传统大红色刻板印象，采用年轻鲜活的「柿系」配色：

| 色彩角色 | 色值参考 | 应用场景 |
| :--- | :--- | :--- |
| 主色·柿红 | `#E85A4F` | 品牌标识、核心按钮、活动氛围、重点强调 |
| 辅助色·鹅黄 | `#F9D56E` | 标签、提示、次级按钮、装饰元素 |
| 辅助色·草绿 | `#88B78F` | 成功状态、福利标识、清新场景搭配 |
| 基础色·米白 | `#FAF7F2` | 页面背景、卡片底色，营造柔和质感 |
| 基础色·深棕 | `#5D4037` | 正文文字、说明文字，保证可读性 |

### 3.3 品牌IP：大喜柿
打造拟人化柿子形象作为专属吉祥物，贯穿全平台视觉与交互：
- **基础形象**：分为新郎款（戴黑色小礼帽、领结）与新娘款（戴蕾丝小头纱、手捧小花），圆滚滚体态，元气治愈表情，自带喜气感。
- **场景化变体**：
  - 好物区：扛购物袋的「采购柿」
  - 灵感区：举放大镜的「灵感柿」
  - 游戏区：玩闹的「淘气柿」
  - 工具区：拿计算器的「靠谱柿」
- **衍生应用**：钥匙扣、喜糖贴纸、婚礼挂饰、微信表情包等，作为活动福利与用户周边。

### 3.4 视觉语言规范
整体采用**手绘市集风**，构建沉浸式逛市体验：
- 页面架构：首页默认呈现“大喜市街景”，各功能模块以独立摊位形式排布，点击进入对应区域，摆脱传统工具类小程序的冰冷列表感。
- 装饰元素：小彩旗、气球、便签贴纸、购物袋、摊位遮阳伞等市集元素，点缀页面各处，营造热闹又清新的氛围。
- 交互动效：摊位 hover 轻微上浮、切换页面模拟“逛到下一个摊位”的平移效果，强化场景代入感。

## 四、产品功能架构（市集化分区）
完全围绕「市集」概念做功能分区，形成「逛-买-玩-交-用」的完整用户动线。

### 4.1 好物市集 · 核心电商区
对应市集特色摊位，主打小众高性价比婚品
- **品类布局**：接亲道具、婚饰首饰、喜糖包装、婚房布置、婚礼伴手礼、小众婚纱六大类，精选网红款、设计师款，拒绝同质化通货。
- **特色玩法**：
  - 每日闪购：每日10点上线限量低价爆品
  - 三人拼团：邀请好友拼单享专属折扣
  - 9.9元喜市小摊：低价引流专区，汇聚小物件、小装饰
  - 闲置转卖通道：支持用户转卖闲置婚品，形成内部流转

### 4.2 灵感摊位 · 内容种草区
对应市集创意展示区，解决婚礼灵感焦虑
- **内容形式**：短图文+竖屏短视频为主，轻量化、易消费
- **核心栏目**：
  - 《避坑摊主说》：过来人分享婚庆踩坑经验、行业套路揭秘
  - 《懒人备婚模板》：可直接复用的流程表、接亲脚本、誓词模板，一键保存
  - 《社恐婚礼指南》：主打减少尴尬环节的轻婚礼方案，精准击中社恐用户
  - 《低成本出片教程》：千元级婚礼布置、拍照技巧分享

### 4.3 搭子广场 · 社交互动区
对应市集休息交流区，打造新人专属社交场
- **备婚搭子匹配**：按婚期、城市、备婚阶段自动匹配同频搭子，支持拼单、吐槽、约看场地
- **话题市集**：每周发起热门讨论，如“婚礼上最想取消的环节”“备婚奇葩经历”
- **互助功能**：闲置婚品互换、备婚资料共享、异地婚礼求助

### 4.4 游戏杂货铺 · 特色玩水区
对应市集游艺摊位，强化潮玩差异化
- **接亲游戏库**：上百种堵门游戏、惩罚方式、问答题目，按难度、风格分类，支持一键生成游戏清单，可导出打印
- **婚礼互动工具**：电子抽奖、弹幕签到、现场真心话大冒险等轻工具，免费使用
- **趣味测试**：婚礼风格测试、备婚焦虑指数测试，自带社交传播属性

### 4.5 喜柿便利店 · 实用工具区
对应市集便民便利店，主打轻量化刚需工具
- 核心工具：预算计算器、宾客名单管理、席位排布生成、黄道吉日查询、备婚倒计时
- 设计原则：即开即用、操作极简，不做复杂深度功能，保持产品轻量化体验

### 4.6 用户核心动线
进入小程序 → 逛灵感摊位找方向 → 好物市集采购婚品 → 搭子广场交流吐槽 → 喜柿便利店落地执行 → 分享内容获得福利

## 五、内容生态运营体系
### 5.1 内容分层体系
- **PGC官方内容**：打造专业靠谱的官方人设，输出干货攻略、避坑指南、活动公告
- **PUGC达人内容**：签约小众婚庆博主、资深司仪、婚礼设计师，产出深度内容与专栏
- **UGC用户内容**：鼓励新人分享备婚日常、婚品开箱、婚礼现场，形成真实社区氛围

### 5.2 固定栏目化运营
| 栏目名称 | 更新周期 | 内容定位 |
| :--- | :--- | :--- |
| 周一喜市播报 | 每周一 | 本周闪购预告、热门灵感合集、平台新鲜事 |
| 周三摊主连线 | 每周三 | 达人直播分享干货+专属福利带货 |
| 周五吐槽大会 | 每周五 | 发起话题讨论，置顶优质评论送周边 |

### 5.3 UGC激励机制
- 发起#我的大喜市备婚日记#长期话题，用户发布备婚内容即可参与
- 每周评选10位「优质摊主」，发放50元婚品优惠券+200喜柿积分
- 优质内容可获得首页流量扶持，入选灵感摊位精选，满足用户成就感

## 六、用户增长与品牌传播策略
### 6.1 线上内容种草：小红书/抖音主阵地
- **核心切入点**：主打“备婚焦虑救星”“懒人备婚神器”，避开与传统婚庆平台正面竞争
- **达人矩阵**：以素人新人、小众备婚博主、婚礼化妆师为主，用“挖到宝了”“备婚人天堂”的口吻真实种草
- **爆款选题方向**：
  - 《备婚不用瞎逛，这一个小程序就够了》
  - 《社恐婚礼必备！接亲游戏全程不尴尬》
  - 《500块搞定婚房布置，大喜市也太好逛了》

### 6.2 社交裂变：基于新人圈层的传播
- **「凑份子」拼团裂变**：邀请2位好友拼团婚品，双方均享额外折扣，利用备婚社交圈快速扩散
- **备婚搭子盲盒**：填写婚期+城市，匹配1位同阶段备婚搭子，邀请好友注册解锁更多匹配机会
- **喜柿分享礼**：分享小程序给好友，双方各得100喜柿积分，可兑换婚品或周边

### 6.3 线下联动：渗透本地婚庆场景
- 与各地婚博会、婚庆市集、婚纱展合作，设置「大喜市快闪摊位」，扫码注册送大喜柿钥匙扣、喜糖贴纸
- 和本地小众婚纱店、婚礼场地、花艺工作室联名，推出「大喜市专属优惠」，打通线上线下流量

### 6.4 节点营销：借势造节拉增长
- **情人节/520/七夕**：推出「限定喜市」主题活动，上线情侣备婚礼包、专属婚品礼盒，搭配趣味互动提前圈粉年轻情侣
- **结婚旺季（3-5月、9-10月）**：打造「大喜市备婚节」，全场婚品折扣、免费解锁高级模板、1v1备婚咨询，打造平台专属大促
- **双11/双12**：婚品囤货节，主打全年最低价，拉动交易增长

## 七、商业盈利模式
### 7.1 交易佣金收入
- 第三方商家入驻，按交易额收取5%-8%的平台佣金
- 拼团、闪购等活动交易，抽取相应比例服务费

### 7.2 商家增值服务
- 摊位展位费：首页推荐位、品类顶部摊位，按月收取展示费
- 推广增值：关键词搜索置顶、内容种草植入、直播带货坑位费

### 7.3 自营与周边收入
- 大喜柿IP周边自营：钥匙扣、喜糖盒、婚礼装饰等定制周边
- 联名定制婚品：与设计师联名推出平台专属款婚品，赚取差价

### 7.4 工具增值服务
- 免费基础工具+付费高级功能：如定制席位图、专属备婚方案、Excel模板导出等
- 1v1备婚咨询服务：对接资深备婚顾问，按次/按套餐收费

### 7.5 广告收入
- 开屏广告、弹窗广告、banner广告等品牌展示广告
- 内容软植入：灵感摊位内容合作、栏目冠名

## 八、品牌调性与沟通规范
### 8.1 核心沟通人设
懂行又靠谱的备婚闺蜜——接地气、会吐槽、懂网络梗，既能共情备婚烦恼，也能给出实在解决方案。

### 8.2 语气原则
- 说人话，不说官话套话
- 有情绪，能共情也能玩梗
- 够直白，不玩文字游戏与消费套路

### 8.3 禁用词汇
禁用「奢华、尊享、顶级、完美、盛大、高端」等传统婚庆厚重词汇，避免给用户造成压力与距离感。

## 九、落地执行阶段规划
### 9.1 冷启动期（0-3个月）
- 产品：上线核心四大模块（好物、灵感、工具、社交），完成基础交互打磨
- 用户：招募1000名种子用户（备婚新人、婚庆博主），收集反馈迭代产品
- 内容：搭建基础内容库，填充100+篇灵感内容、50+接亲游戏模板
- 商家：签约50家小众婚品商家，完成首批商品上架

### 9.2 成长期（3-9个月）
- 产品：迭代游戏杂货铺、闲置转卖等特色功能，优化用户体验
- 用户：启动小红书/抖音种草，目标用户量突破10万，日活突破1万
- 商家：拓展至200+商家，覆盖全品类婚品与本地婚庆服务
- 运营：落地固定栏目运营，启动首次备婚节大促

### 9.3 成熟期（9-18个月）
- 产品：完善生态闭环，推出付费增值服务，探索直播带货
- 用户：用户量突破50万，打造多个爆款传播案例，建立品牌认知
- 商业化：全面开启商业化，实现盈亏平衡，拓展线下联名合作
- 品牌：沉淀品牌心智，成为年轻群体备婚首选平台之一

## 十、风险与应对方案
1. **同质化竞争风险**
   - 应对：强化「市集化」「潮玩化」差异化定位，深耕社交与游戏特色模块，打造不可替代的情绪价值
2. **用户留存率低**
   - 应对：通过固定栏目运营培养用户访问习惯，搭子社交强化用户粘性，用积分体系提升留存
3. **商家与商品质量管控**
   - 应对：建立商家准入审核机制，实行用户评分淘汰制，先行赔付保障用户权益
4. **内容生态冷启动难**
   - 应对：种子用户激励+达人签约双管齐下，官方产出优质内容打底，逐步引导UGC生产
